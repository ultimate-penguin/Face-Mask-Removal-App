# Face Mask Removal Using GAN and Streamlit

## 📌 Overview

This project is a deep learning application that removes face masks from facial images using a **Generative Adversarial Network (GAN)**. The trained model predicts and reconstructs the masked facial regions to generate an unmasked face. A **Streamlit** web application provides an intuitive interface for users to upload images and view the generated results.

This project demonstrates the application of generative AI, computer vision, and web deployment in an end-to-end machine learning workflow.

## ✨ Features

* Upload an image containing a masked face and a binary mask (facemask region= white, other regions=black)
* Select a generator model
* Generate an estimated unmasked version using a GAN model
* Interactive web interface built with Streamlit
* Simple and user-friendly design
* Real-time image visualization

## mask.py
* mask.py is a python script for extracting the binary mask from the facemask image. It only works for images from the datasets or when both without facemask image and added facemask image are available.
If only facemask image is available, it is necessary to extract binary mask image with other tools first before inputting in streamlit.

## 📖 How to Use

1. Start the Streamlit application.
2. Upload an image containing a face with a mask and a binary mask.
3. Select a generator model
4. Click the **Process** button.
5. View the reconstructed unmasked face generated by the GAN.

## 🧠 Model

The project uses a **Generative Adversarial Network (GAN)** consisting of:

* **Generator:** Learns to reconstruct the masked facial regions and generate a realistic unmasked face.
* **Discriminator:** Distinguishes between real unmasked faces and generated images, encouraging the generator to produce more realistic results.

The adversarial training process improves image quality over time, enabling the model to generate visually convincing reconstructions.

This project tried 2 generator's architectures: the encoder-decoder model and the 3-level U-NET model

## Project Scope

This project focuses on building an end-to-end GAN application, including model development, inference, and deployment using Streamlit. Due to computational resource limitations, the model was trained for **5 epochs**. Despite the limited training duration, the project successfully demonstrates the complete workflow and serves as a functional proof of concept.

---

## 📊 Results

The models are capable of reconstructing skin color and texture but cannot generate accurate facial features beneath masks which could be due to simple architecture and few training epochs. Furthermore, the models perform better on test images from the same Kaggle dataset than test images obtained elsewhere. Although the reconstructed faces are not accurate and have low resolution, it demonstrates the potential of GANs for image completion and facial inpainting tasks.

## ⚠️ Limitations

* Generated faces are predictions and do **not** represent the person's actual appearance.
* Performance depends on image quality, lighting, and face orientation.
* Extreme occlusions or unusual masks may reduce reconstruction quality.
